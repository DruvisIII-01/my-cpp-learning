# 并查集（data-structures/dsu）

> 本目录共 **1** 个题解文件（2026-10 第三轮整理新建）。

## 一、这一类题在考什么

并查集维护"等价类"的合并与查询。本目录从基础实现一路到**带关系的种类并查集**。

## 二、关键思路与套路

- **基础三件套**：`fa[x] = x` 初始化、`find` 带路径压缩、`union` 合并两个集合。
- **种类并查集（带权/带符号）**：把"x 与 y 相等/相反"编码成边上的符号。`LGP9869`（CSP-S 2023 三值逻辑）用 `fa` 与"取反"的相互递归 `find(-fa[-x])` 传递符号，并用 T/F/U 三个特殊点表示常量。
- **无解判定**：若某变量的取值最终**只可能与自身相反**（即 U），说明它无法确定或矛盾，本题统计的就是必须取 U 的变量个数。
- **扩展域（拆点）写法**：把每个变量拆成 x 与 x+n 两个点表示"真/假"，等价关系用并查集合并，这是种类并查集的另一种常见实现（比带符号递归更好写）。
- **常见变体**：可撤销并查集（按秩合并、无路径压缩）、带权并查集（维护到根的差值）、并查集 + MST。

## 三、最容易踩的坑

- 带符号递归的 `find` 最容易写错：要在路径压缩时**同时压缩正负两个方向**，并注意访问 `-x` 时的下标越界与递归环（用 book[] 标记）。建议初学时先写"拆点(扩展域)"版本，更好调。
