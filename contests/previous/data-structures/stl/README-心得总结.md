# STL 与容器技巧

> 本目录共 **5** 个题解文件。

## 一、这一类题在考什么

很多"数据结构题"其实只需要选对容器 + 一个观察。

## 二、关键思路与套路

- `map/set`：按值统计与去重（CF790F 频率筛选、CF940C 二元组计数）。
- `priority_queue`：多关键字取最优（CF944G 对每组用小根堆排序填回）。
- `deque`：双端操作 + 维护聚合量（CF1017G 用两个双端队列维护环上两两乘积和，旋转时 `cool = l*sum - cool`）。
- `multiset`：动态维护多重集极值/频次（CF971G1 维护区间众数出现次数）。
- `stack`：括号匹配（CF1096B）。
- 选容器先问：要不要有序？要不要计数？要不要快速取极值？

## 三、最容易踩的坑

- 先问"需要支持什么操作"再选结构；能用一个 STL 容器解决就别手写数据结构。
