# 线段树与懒标记

> 本目录共 **2** 个题解文件。

## 一、这一类题在考什么

区间修改 + 区间查询的通用结构，难点全在 **lazy 标记的定义与下传顺序**。

## 二、关键思路与套路

- LGP3372：区间加 + 区间和，`sum[]` 与 `add[]` 两个数组，pushdown 把标记累加到孩子。
- LGP3373：区间乘 + 区间加 —— **先乘后加** 约定下，下传 mul 时 add 也要乘 mul。
- 通用建议：写 `pushup` / `pushdown` / `build` / `update` / `query` 五个函数，边界用闭区间。
- 多标记时务必想清"标记的作用顺序"，并用小数据（n = 4）手推一遍。
- 注意：并非所有"带区间查询"的题都用线段树——CF1109E 最终是用二分解决（已归入 binary-search）。

## 三、最容易踩的坑

- 先问"需要支持什么操作"再选结构；能用一个 STL 容器解决就别手写数据结构。
