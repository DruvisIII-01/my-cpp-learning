# 树状数组

> 本目录共 **2** 个题解文件。

## 一、这一类题在考什么

BIT 擅长**单点更新 + 前缀查询**，代码短、常数小，是逆序对与值域统计的首选。

## 二、关键思路与套路

- 三基本操作：`add(i, v)`、前缀和 `sum(i)`、区间和 `sum(r) - sum(l-1)`。
- 求逆序对：从左到右 `ans += i - sum(a[i])`。CF790H2 统计 `a[j] >= a[i]`，答案为 `Σ(前面 ≤ a[i] 的个数) + C(相同值个数, 2)`。
- 前缀最大值型 BIT：CF1109G 把 dp[i] 在 `i + a[i] + 1` 时刻插入，求 `[1, i-a[i]-1]` 的最大 dp。
- 值域含负数或很大时先离散化。
- `lowbit(x) = x & -x`；循环 `for (; i <= n; i += lowbit(i))` 别写反。

## 三、最容易踩的坑

- 先问"需要支持什么操作"再选结构；能用一个 STL 容器解决就别手写数据结构。
