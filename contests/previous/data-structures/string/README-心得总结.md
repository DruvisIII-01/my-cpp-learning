# 字符串处理

> 本目录共 **3** 个题解文件。

## 一、这一类题在考什么

本目录以"字符串上的模拟 + 哈希表"为主，进阶的 KMP/Trie/后缀结构可以后续补充。

## 二、关键思路与套路

- CF806D（Double Strings）：串放进 `map/set`，枚举每个串的拆分点判断两半是否都在集合中。
- CF940B：字符去重排序后建立镜像映射 `r[i] ↔ r[len-1-i]`，逐字符替换。
- CF1017D：把两个串切成"极小连续相同段"，逐段比较长度是否满足 `a[i] ≤ b[i] ≤ 2a[i]`；**分段比较**是字符串模拟的通用套路。
- 建议补做：字符串哈希、KMP、Z 函数、Trie、Manacher。

## 三、最容易踩的坑

- 先问"需要支持什么操作"再选结构；能用一个 STL 容器解决就别手写数据结构。
