# 暴力与枚举

> 本目录共 **16** 个题解文件。

## 一、这一类题在考什么

先估复杂度再写代码。**枚举什么量** 是这类题的全部难点。

## 二、关键思路与套路

- **枚举答案的候选值**：CF661C 枚举配对重量和（≤ 2n）；CF667C 枚举 y-x 的约数当公差；LGB4426 枚举两个分界点。
- **枚举 + 预处理降复杂度**：CF1006D 枚举区间后用计数表 O(1) 评估；CF1093C 枚举拐点并利用四方向连续段长度。
- **鸽巢/剪枝**：CF799F 每种尾数只留 3 个数，再枚举三元组。
- **按位/数位枚举**：ECF188E 枚举数位和与最高位；CF1098C 枚举第一个不同的数位后贪心填数。
- CF790H1（O(n²)）与 CF790H2（树状数组）成对存在，是"从暴力到优化"的最佳对照，建议都留着。

## 三、最容易踩的坑

- 写暴力前先算 n² 是否可接受；不要把"枚举 + 判断"写成"搜索 + 回溯"。
