# 数位 DP

> 本目录共 **3** 个题解文件。

## 一、这一类题在考什么

数位 DP 是**按位枚举 + 记忆化**的通用框架，模板比技巧更重要。

## 二、关键思路与套路

- 状态四要素：`当前位 pos`、`已累计信息`、`是否贴上界 free`、`是否已起头 is_num`。
- **前导零必须单独处理**：LGP2602 统计 0 的个数时前导零不计入，用 `is_num` 标记。
- **区间转前缀差**：`f(b) - f(a-1)`。
- 记忆化只对非贴界状态生效：`if (!free && dp[...] != -1) return dp[...]`。
- 变体：LGP1836 累加数位和；LGP1708 统计"数位和 ≤ k 的数的个数"。

## 三、最容易踩的坑

- 先写 O(n²) 朴素转移验证正确，再优化；环形问题特判首尾相接。
