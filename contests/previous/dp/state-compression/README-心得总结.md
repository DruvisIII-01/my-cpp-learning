# 状压 DP

> 本目录共 **1** 个题解文件。

## 一、这一类题在考什么

用二进制表示集合，适合 n ≤ 20 的"集合/排列"型问题。

## 二、关键思路与套路

- LGP1433（吃奶酪）：`dp[i][S]` 表示当前在 i、已访问集合 S 的最短距离，S 不含起点。
- 枚举：`for (S) for (i in S) for (j not in S) dp[j][S|1<<j] = min(...)`。
- 复杂度 O(2ⁿ·n²)，n = 15 时约 7e6，可过。
- 常见姊妹题：TSP、铺砖、集合覆盖。

## 三、最容易踩的坑

- 先写 O(n²) 朴素转移验证正确，再优化；环形问题特判首尾相接。
