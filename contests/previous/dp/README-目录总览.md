## 通用方法论

- 先想清"状态、代价/收益、转移来源"，再写代码。
- 先写 O(n²) 朴素转移并验证，再考虑前缀和 / 单调队列 / 线段树优化。
- 树形 DP 的固定套路：`dfs(u, fa)` 返回子树信息，父节点再按"选/不选"或"大小限制"合并。
- 计数类 DP 注意去重；每道题都问一句：状态能不能再压一维？
