# 线性与序列 DP

> 本目录共 **17** 个题解文件。

## 一、这一类题在考什么

数量最多的一类 DP：状态沿下标推进，难点在**状态定义**与**转移优化**。

## 二、关键思路与套路

- **状态定义决定一切**：LGP1103（保留 k 本书）、LGP14746（三状态：空闲/持有/结算）、CF1109D（奇偶两态）。
- **前缀和/滑窗优化**：LGP6323（逆序对计数 DP 的转移是滑动窗口和）。
- **单调队列优化**：LGP4954（Tower of Hay，决策点单调）。
- **发现"状态有限"**：CF806G 中坏钥匙用超过 32 次后收益恒为 0，状态数压到 33。
- **LIS 及其变体**：LGP3902（n - LIS）、LGP1108（LIS 计数，注意 `a[j]==a[i] && f[j]==f[i]` 时去重）。
- **期望型 DP**：CF1086C 倒序 `dp[i] = max(c[i] + dp[i+1]*r[i], dp[i+1])`。
- **环形/字符串 DP**：LGP1057（下标模 n）、ABC456B/D、LGP14075（划分字符串）。

## 三、最容易踩的坑

- 先写 O(n²) 朴素转移验证正确，再优化；环形问题特判首尾相接。
