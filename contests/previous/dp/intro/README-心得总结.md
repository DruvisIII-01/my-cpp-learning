# 递推入门

> 本目录共 **1** 个题解文件。

## 一、这一类题在考什么

入门级 DP/递推，重点是**把状态转移写到纸上再上机**。

## 二、关键思路与套路

- LGP1002（过河卒）：先标记马及其 8 个控制点为不可达，再用 `f[i][j] = f[i-1][j] + f[i][j-1]`。
- 边界：起点 `f[0][0] = 1`，越界/障碍处为 0。
- 计数类 DP 答案可能很大，注意 `long long`。
- 后续可补：数字三角形、LIS 入门、背包入门。

## 三、最容易踩的坑

- 先写 O(n²) 朴素转移验证正确，再优化；环形问题特判首尾相接。
