# 模拟与实现

> 本目录共 **14** 个题解文件。

## 一、这一类题在考什么

没有算法，只有细节。考的是代码组织能力与下标约定。

## 二、关键思路与套路

- **下标约定统一**：本项目大量使用"输入时补一个 `*` 前缀（1-indexed）"，能显著减少越界。
- **网格题三手法**：按行列统计（CF786G 重力下落）、对角线预处理（CF790D）、分组取最优（CF806E 旋转四元组）。
- **时间类模拟**：CF799D 枚举 1440 分钟内的所有时刻判回文。
- **字符串/数组细节**：CPL0404A/B 是纯模拟，注意 C 语言与环形下标。
- 模拟题建议先写清"输入 → 状态表示 → 输出"三段再动手；改 bug 优先怀疑下标。

## 三、最容易踩的坑

- 模拟题先定好下标与状态表示，再动手。
