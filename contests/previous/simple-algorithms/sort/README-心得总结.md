# 排序、排序后处理与前缀和

> 本目录共 **14** 个题解文件，由 `basics / implementation / brute-force / greedy` 中挑选出的代表性题目组成。

## 一、这一类题在考什么

排序本身不是难点，"排完之后怎么用"才是：相邻差、配对、双指针、前缀和、去重、枚举候选值。

## 二、关键思路与套路

- **排序后取相邻差**：CF661B（两个数组各自降到最小值，一次操作可同时减两者，代价 = Σmax(Δa, Δb)）。
- **排序后贪心装箱/配对**：CF1087A（按容量 c 成组、组内相邻差 ≤ k）、CF693D（两人轮流取当前最大值，排序后模拟即最优）。
- **排序后模拟对抗**：CF1086B（按奇偶分组，两人轮流取各自可取的最大值）。
- **"第一个下降点"型扫描**：CF656B（从右往左找最长合法后缀，答案 = 该下标 − 1）。
- **前缀和 / 差分 / 分层计数**：CF640E（O(n²) 枚举所有子段和并标记哪些元素可被表示）、CF898C（10×10 靶盘按到边界的层数计分）、CF806E（旋转四元组分组，每组取 min(cnt, 4−cnt)）、CF971D（按 (x, y) 建表后逐 x 计数）、CF1089B（代价为 0 的椅子优先坐满）。
- **枚举 + 排序双指针**：CF661C（枚举目标和 s ≤ 2n 后双指针配对）、CF1090E（最大异或对的暴力枚举版）。
- **按位贪心（"排序思路"的位版本）**：CF786H（从高位到低位凑最大 AND，统计该位为 0 的个数 c，k ≥ c 就置位）。
- **鸽巢剪枝**：CF799F（只保留每种尾数的 3 个数，再暴力枚举三元组）。
- **从暴力到优化的对照**：CF790H1（O(n²) 求 max 逆序对）对应 `data-structures/fenwick/CF790-H2`（树状数组 O(n log n)），建议两版对照着看。

## 三、最容易踩的坑

- 排序后别忘了处理"相等元素"：逆序对题里 CF790H1 统计的是 `a[j] >= a[i]`（含相等），配对题里相等元素往往要单独讨论。
