# 双指针与滑动窗口

> 本目录共 **3** 个题解文件。

## 一、这一类题在考什么

双指针成立的前提是**单调性**：左端点右移时右端点不会左移。

## 二、关键思路与套路

- CF786F（Eating Candies）：左右前缀和相等，哪边和小就往哪边扩。
- CF898F（Money Trees）：先满足"相邻高度整除"的窗口约束，再在窗口和 ≤ k 下取最长。
- CF640D（Alice/Bob）：左右指针模拟每回合"必须比上回合多"。
- ABC475F：枚举上下边界后左右指针维护各列计数，把 O(n⁴) 压到 O(n³)。
- 模板骨架：`for (l...) { while (r+1 <= n && ok(r+1)) add(++r); update(ans); del(l); }`。

## 三、最容易踩的坑

- 注意边界与数据类型。
