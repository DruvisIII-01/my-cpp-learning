# 二分（二分答案 / 有序结构上二分）

> 本目录共 **3** 个题解文件。

## 一、这一类题在考什么

分成两类：**二分答案**（对答案的单调性二分 + check）与**在有序结构上二分查找**（lower_bound 思想）。

## 二、关键思路与套路

- 二分答案三条件：答案有界、有单调性、check(x) 可 O(n) 完成。
- **CF1109E（Masha and the Garland）**：把 s 与两种交替目标串逐位比较得到若干"极大失配段"，翻转一段只能修正一个失配段，故最少操作数 = 区间内失配段数；预处理段列表 + 每次询问二分，O((n+q) log n)。
- CF898E：二分层高 h，用水量 Σmax(0, h-a[i]) 随 h 单调递增。
- CF971E：前 m 项与后 n-m 项之差的绝对值先减后增，二分/三分找零点再比较相邻两项。
- ABC449C：对每个字符的有序位置表二分 `[i+L, i+R]` 的端点。
- 模板统一写成 `while (L + 1 != R)` 的半开区间形式，避免死循环与 ±1 错误。

## 三、最容易踩的坑

- 单调性证不清就不要上二分；上界要开够（用 1e18 而不是 1e9）。
