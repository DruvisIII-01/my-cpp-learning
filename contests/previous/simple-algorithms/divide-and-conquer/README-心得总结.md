# 分治

> 本目录共 **1** 个题解文件。

## 一、这一类题在考什么

把区间折半后递归，重点在"合并/统计跨区间贡献"的那一步。

## 二、关键思路与套路

- CF656D：`solve(l, r, c)` 表示把区间 [l,r] 变成"以 c 为起点的好串"的最小代价。
- 转移：左半全改成 c + 递归右半（c+1），与对称情况取 min。
- 复杂度 O(n log n)（每层总长 n，共 log n 层）。
- 后续可补：归并求逆序对、CDQ 分治、整体二分、分治 + 单调栈。

## 三、最容易踩的坑

- 注意边界与数据类型。
