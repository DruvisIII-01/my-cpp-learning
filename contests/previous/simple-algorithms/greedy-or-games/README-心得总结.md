# 贪心

> 本目录共 **17** 个题解文件。

## 一、这一类题在考什么

贪心的合法性来自**交换论证**或**决策单调性**，不是"感觉这样最优"。

## 二、关键思路与套路

- **排序贪心**：CF1087A、CF661B、CF693D 都是排序后按规则取。
- **扫描式贪心**：CF1109B 用 rest 累计盈余、不足时回补，是"可行性判定"的经典写法。
- **代价为 0 优先**：CF1089B 先坐满 p[i] ≤ i 的椅子（交换论证）。
- **观察式贪心**：CF898G 只需判断串首/串尾是否为 B，否则牺牲最短的纯 A 段。
- CF799E 表面贪心，实际是"和为 target 的最长连续段"（滑动窗口）。
- 优先队列贪心可见 graphs/dfs/CF662-E1.cpp（每次减半收益最大的边）。

## 三、最容易踩的坑

- 贪心写完一定要试反例 3 分钟；能用 DP 不用贪心时优先 DP。
