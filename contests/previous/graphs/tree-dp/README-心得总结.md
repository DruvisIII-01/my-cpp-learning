# 树上 DP（graphs/tree-dp）

> 本目录共 **1** 个题解文件（2026-10 第三轮整理新建）。

## 一、这一类题在考什么

在树上做 DP：状态挂在节点上，转移沿父子边进行。核心是"先递归处理子树，再用子树信息更新自己"。

## 二、关键思路与套路

- **经典模型——没有上司的舞会（LGP1352）**：`dp[x][1] = r[x] + Σ dp[son][0]`，`dp[x][0] = Σ max(dp[son][0], dp[son][1])`。选与不选父节点决定子节点能不能选。
- **建树与找根**：读入 n−1 条边后，用 `is_root[]` 标记谁当过儿子，剩下那个就是根；也可以用邻接表从任意点 DFS 定根。
- **两种写法**：返回结构体（本目录的写法，直观）或全局 `dp[MAXN][2]` 数组（更省内存）。
- **常见变体**：树的最大独立集、树上背包、换根 DP、树的直径、最小支配集。
- 递归前想清楚：**状态的定义、初始值、以及"父节点状态如何限制子节点"**。

## 三、最容易踩的坑

- 注意树可能给的是"儿子→父亲"方向（本题 `add(k, l)` 表示 k 是 l 的上司），建边方向反了就找不到根。
