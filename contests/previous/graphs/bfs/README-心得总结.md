# 广度优先搜索 BFS

> 本目录共 **2** 个题解文件。

## 一、这一类题在考什么

BFS 的两种经典用途：**无权最短路/多源扩散** 与 **染色判定**。

## 二、关键思路与套路

- ABC472D：所有"安全行列交点"作为多源起点入队，BFS 深度 ≤ k 统计可达格。
- ABC472E：BFS 交替染色判二分图；遇到同色冲突边则沿 BFS 树回溯到 LCA 得到奇环。
- 技巧：多源 BFS 一次性入队；用 `dist[]` 代替 `vis[]` 同时记录层数。
- 入队时就要标记 visited，否则会重复入队导致 TLE/MLE。

## 三、最容易踩的坑

- 图论题第一步永远是"点数/边数多大、有没有重边自环、要不要开 2 倍边"；多测清空全局数组。
