# Tarjan 与强连通分量

> 本目录共 **2** 个题解文件。

## 一、这一类题在考什么

`dfn`/`low` 双数组 + 栈，是 SCC、割点、割边、双连通分量的统一工具。

## 二、关键思路与套路

- 核心判断：`low[v] >= dfn[u]` ⇒ u 是割点；`low[v] > dfn[u]` ⇒ (u,v) 是割边。
- 强连通分量：`low[u] == dfn[u]` 时弹栈直到 u，弹出的点构成一个 SCC。
- LGB3609 是 SCC 模板题；注意题目允许重边与自环，输出顺序按题面要求排序。
- 与 2-SAT 联用（见 graphs/2sat）。
- 链式前向星边编号从 1 开始（配合 `i ^ 1` 取反向边）；多测要清 `dfn/low/top`。

## 三、最容易踩的坑

- 图论题第一步永远是"点数/边数多大、有没有重边自环、要不要开 2 倍边"；多测清空全局数组。
