# 最小生成树（graphs/mst）

> 本目录共 **2** 个题解文件（2026-10 第三轮整理新建）。

## 一、这一类题在考什么

MST 是"用最小代价把所有点连通"的经典模型，Kruskal（并查集 + 排序）是最常用的实现。

## 二、关键思路与套路

- **Kruskal 骨架（LGP3366 模板）**：按边权升序排序，用并查集判断两端是否已连通，不连通就选这条边并累加，选够 n−1 条结束。
- **复杂度**：O(m log m)（排序主导），适合稀疏图；稠密图可用 Prim（O(n²) 或堆优化）。
- **判连通**：选够 n−1 条边才合法，否则图不连通（模板题输出 `orz`）。
- **虚拟点建图（LGP1550 打井）**：新建点 n+1 表示"井"，把"在某点打井"变成虚拟点与它的边，从而把"点权"转化为"边权"，直接套 MST。这是非常常用的建模技巧。
- **常见变体**：次小生成树、最小瓶颈路、MST 计数、Kruskal 重构树。

## 三、最容易踩的坑

- 并查集要写路径压缩，否则在 2e5 规模上可能超时；注意边数组大小按 **m**（不是 n）开。
