# 拓扑排序

> 本目录共 **2** 个题解文件。

## 一、这一类题在考什么

DAG 上的线性化工具，也是"判环"与"依赖关系"的标准解法。

## 二、关键思路与套路

- 模板：入度 0 入队，出队时邻居入度减 1，减到 0 再入队；出队点数 < n 则有环。
- LGB3644 是纯模板（家谱树）。
- CF656E（Directing Edges）：**先给原有向边拓扑排序，成环则无解；否则按拓扑序给无向边定向**，结果必是 DAG。
- 拓扑序也常用于 DAG 上 DP 的推进顺序。

## 三、最容易踩的坑

- 图论题第一步永远是"点数/边数多大、有没有重边自环、要不要开 2 倍边"；多测清空全局数组。
