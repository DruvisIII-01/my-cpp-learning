# 深度优先搜索 DFS

> 本目录共 **2** 个题解文件。

## 一、这一类题在考什么

DFS 的三种角色：遍历、回溯维护路径状态、树形统计（子树信息）。

## 二、关键思路与套路

- ABC448D：用 multiset 维护"根到当前节点"的路径值，进入时判重、回溯时撤销。
- CF662E1（Weights Division）：DFS 预处理每条边被多少叶子路径经过，把树上操作转成"按收益排序的贪心"。
- 通用框架：`dfs(u, fa)` 内先处理进入、递归孩子、再处理回溯。
- 深递归注意栈深度（可改迭代或加大栈）。

## 三、最容易踩的坑

- 图论题第一步永远是"点数/边数多大、有没有重边自环、要不要开 2 倍边"；多测清空全局数组。
