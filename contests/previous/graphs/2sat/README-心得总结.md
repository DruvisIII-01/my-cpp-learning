# 2-SAT

> 本目录共 **1** 个题解文件。

## 一、这一类题在考什么

每个变量两种取值 + 若干二元约束 ⇒ 建蕴含图 + SCC 判定。

## 二、关键思路与套路

- 建图：`(x = a) 或 (y = b)` 拆成 `¬(x=a) → (y=b)` 与 `¬(y=b) → (x=a)`。
- 判定：Tarjan 缩点后若 `x` 与 `¬x` 同 SCC 则无解。
- 取解：SCC 编号大的取真（`comp[x] < comp[¬x]` 时 x 为真）。
- 变量与文字编号约定要全程一致。

## 三、最容易踩的坑

- 图论题第一步永远是"点数/边数多大、有没有重边自环、要不要开 2 倍边"；多测清空全局数组。
