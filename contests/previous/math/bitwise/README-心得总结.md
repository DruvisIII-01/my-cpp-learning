# 位运算

> 本目录共 **3** 个题解文件。

## 一、这一类题在考什么

按位独立是位运算题的灵魂：**每一位互不影响，可以逐位贪心/统计贡献**。

## 二、关键思路与套路

- CF1017E：统计每一位 0/1 的个数，选 a[i] 使异或总和最大，逐位算贡献 `2^k × 与该位相反的个数`。
- CF1009C：`x & (x-1) == 0`（2 的幂）或 `(x+1) & x == 0`（2^k-1）都不合法。
- CF786C：奇偶性即最低位，按位分类讨论。
- 常用恒等式：`x & (x-1)` 去最低位 1；`x & -x` 取最低位 1；`x | (1<<k)` 置位。
- 更难的按位贪心（最大 AND）见 brute-force/CF786H。

## 三、最容易踩的坑

- 溢出与浮点是头号敌人：lcm 先除后乘，能整数开方就别用 sqrt。
