# 计算几何与整点计数

> 本目录共 **4** 个题解文件。

## 一、这一类题在考什么

本目录以**整点计数**为主，核心是"避免浮点 + 把几何条件转成整数不等式"。

## 二、关键思路与套路

- CF1009D：枚举每列横坐标 j，纵坐标范围长 `2*sqrt(r² - (j-x)²) + 1`；map 对每列取所有圆的最大高度后累加。
- **整数开方**：写 `isqrt(x)` 用调整型牛顿/二分，绝不用 `sqrt` 直接转 int（大数会差 1）。
- ABC449D：统计 `|x| ≥ |y|` 且 x 为偶数的整点，按符号分段后等差求和。
- CF944F：到原点距离落在 `[r, r+1)` 的整点计数，同样靠整数开方 + 逐列枚举。

## 三、最容易踩的坑

- 溢出与浮点是头号敌人：lcm 先除后乘，能整数开方就别用 sqrt。
