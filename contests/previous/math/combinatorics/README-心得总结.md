# 组合数学（math/combinatorics）

> 本目录共 **3** 个题解文件。与 `math/patterns` 的区别：**这里明确是"数方案数/数子集/数路径"的计数题**，而 `patterns` 是"找规律/不变量/构造"。

## 一、这一类题在考什么

组合数学回答"有多少种"，核心是把方案拆成**互相独立的选择**，再用加法/乘法原理、组合数、容斥把它算出来。

## 二、关键思路与套路

- **组合数预处理**：杨辉三角 `C[i][j] = C[i-1][j-1] + C[i-1][j]`（`LGP2727` 用它逐位确定第 I 小的串）。
- **容斥原理**：总数 − 至少不满足一个 + 至少不满足两个…（数论里的 lcm 容斥见 `math/number-theory/ECF188C`）。
- **分类计数 + 前缀和**：`LGP8865`（NOIP2022 种花）把网格里的 C 形/F 形方案按拐点分类，用前缀和累加。
- **子序列 / 子集计数**：`CF1122C` 先把 01 串分类，再统计子集方案数。
- **乘法原理 + 逆元**：需要 `n! / k!` 时必须用模逆元（`math/fast-power` 里的费马小定理）。
- **常见变体**：方格路径数 `C(n+m, n)`、错排、卡特兰数、卢卡斯定理、生成函数。

## 三、最容易踩的坑

- **模运算下的除法**：`a / b` 要写成 `a * inv(b)`，且模数必须是素数（否则用 CRT 或质因子分解）。
- **重复计数**：相同的方案被不同路径数了两次，常见于"按起点/按终点"重复枚举，要用容斥或固定代表元。
- **组合数上限**：`C(60, 30)` 就已经超过 `int`，记得开 `long long` 或直接取模。
