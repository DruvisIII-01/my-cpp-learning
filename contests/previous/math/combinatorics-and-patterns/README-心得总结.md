## 一、这一类题在考什么

没有通用算法可套，靠**手玩小数据 → 找不变量/单调量 → 推出统一公式或分类讨论**。

## 二、关键思路与套路

- **找不变量**：`CF1122D` 的关键是 `a[i] - i` 在操作下不变；`CF1114C1/C2` 的充要条件是"1 的个数 + 奇数位 1 的个数"。
- **奇偶性 / 模 k 分类**：`CF693C`、`CF940A`、`CF640C`（第 k 个不被 n 整除的数，按每 n-1 个一组）。
- **手玩小样例**：`CF971C`（两次上取整比较两种跳法）、`CF644C`（排序后看相邻差 1）。
- **抽屉原理**：`CF1086A`（若某色超过 n(n-1) 则无解）。
- **轮流取数的贪心模拟**：`CF1086B`、`CF693C`（带博弈背景但本质是贪心，也可归 `simple-algorithms/greedy-or-games`）。
- **构造/分类讨论**：`CF1090C`、`CF1119D`、`CF1119E`、`CF640B`。

## 三、最容易踩的坑

- 别急着写代码；先在纸上算 n = 1..8 的答案序列（可丢进 OEIS 找灵感）。
- 猜出公式后一定要用 n 很大的边界值验一遍（防溢出 / 防整除边界）。
