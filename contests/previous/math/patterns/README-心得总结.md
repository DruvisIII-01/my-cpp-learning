# 规律与公式推导

> 本目录共 **18** 个题解文件。

## 一、这一类题在考什么

这类题没有通用算法，靠**手玩小数据 → 找不变量/单调量 → 推出统一公式**。

## 二、关键思路与套路

- **找不变量**：CF1122D 的关键是 `a[i] - i` 在操作下不变；CF1114C1/C2 的充要条件是"1 的个数 + 奇数位 1 的个数"。
- **手玩小样例**：CF640C 按每 n-1 个一组；CF971C 用两次上取整比较两种跳法。
- **轮流取数的贪心模拟**：CF693C、CF1086B。
- **前缀和/周期**：CF971F 的无限数组由循环移位块拼接，先算整块再算余数。
- **组合计数**：LGP2727 用杨辉三角逐位确定第 I 小的 01 串；LGP8865 用前缀和统计 C/F 形方案。
- 习惯：**先写暴力打表 → 猜公式 → 证明**。

## 三、最容易踩的坑

- 溢出与浮点是头号敌人：lcm 先除后乘，能整数开方就别用 sqrt。
