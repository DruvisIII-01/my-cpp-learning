# 差分（math/difference）

> 本目录共 **1** 个题解文件。差分是前缀和的逆运算：**在区间上做加减，最后前缀和还原**。

## 一、这一类题在考什么

当操作是"给区间 [l, r] 全体加/减同一个值"，而询问是"最后每个位置的值"时，差分把每次操作降到 O(1)，最后扫一遍前缀和得到结果。

## 二、关键思路与套路

- **一维差分模板**：`d[l] += x; d[r+1] -= x;`，最后 `cur += d[i]` 还原。
- **二维差分**：矩形 (x1,y1)-(x2,y2) 加 v，等价于四个角 `d[x1][y1] += v, d[x2+1][y1] -= v, d[x1][y2+1] -= v, d[x2+1][y2+1] += v`，再做二维前缀和。`CF817E`（Counting Rectangles）正是此套路。
- **差分 + 前缀和互为逆运算**：`ABC478D`（Range Set Insertion Query）对每个时间点把区间合并后用差分标记，再前缀和还原出"被覆盖次数"。
- **差分常与"合并同类操作"一起出现**：同一时刻的区间要先排序合并，再打差分（`ABC478D`）。
- **注意坑**：线段树懒标记本质也是"差分思想"的树上版本，但那种题放在 `data-structures/segment-tree`。

## 三、最容易踩的坑

- `r + 1` 可能越界，数组要开 `n + 2`。
- 多次操作要**累加**到差分数组（`d[l] += x`），不是覆盖。
- 还原时是"前缀和"而不是"原值"，别忘了先做一次 `cur += d[i]`。
