# 前缀和（math/prefix-sum）

> 本目录共 **16** 个题解文件。与 `math/difference` 是**互逆**的一对技巧：前缀和做"区间 → 单点"，差分做"单点 → 区间"。

## 一、这一类题在考什么

前缀和把"多次区间求和"从 O(n) 压到 O(1)。题目往往不难在"求前缀和"本身，而难在**把它用在哪儿**：

- 直接求区间和 / 子段和；
- 配合二分（前缀和单调）；
- 作为 DP 的转移加速（把 O(n) 转移压成 O(1)）；
- 二维前缀和 / 加权前缀和（高维容斥）。

## 二、关键思路与套路

- **一维模板**：`pre[i] = pre[i-1] + a[i]`，区间和 `pre[r] - pre[l-1]`。
- **排序后前缀和 + 二分**：`CF790E`（吃糖查询）、`CF827E`（Scuza：前缀最大值 + 前缀和 + 二分）。
- **前缀和把 check 变 O(1)**：`CF898E`（用水量 `Σmax(0, h-a[i]) = a[mid]*mid - sum[mid]`）、`CF640E`（枚举所有子段和）。
- **计数前缀和**：`CF806F`（`sum[t] = Σ(a[i] < i)`）、`CF1090G`、`LGP2727`（`sum[i][j] = Σ_{k≤j} dp[i][k]`）。
- **前缀和 + 单调队列优化 DP**：`LGP4954`（Tower of Hay）、`LGP6323`（ZBRKA：`dp[j] = pre[j] - pre[j-i]`）。
- **前后缀双向**：`ABC474E`（前缀和 + 后缀和枚举分割点）、`CF784F`（左右段和相等）。
- **二维前缀和**：`ABC475F`（列前缀和）、`CF993H`（二维 + 加权 `i·a`/`j·a` 前缀和，最难的加权容斥）。
- **周期/块状前缀和**：`CF971F`（无限数组由循环移位块拼成，整块 + 余数）。

## 三、最容易踩的坑

- **下标**：统一 1-indexed，`pre[0] = 0`，区间和写 `pre[r] - pre[l-1]` 而不是 `pre[r] - pre[l]`。
- **溢出**：前缀和很容易爆 `int`，一律 `long long`。
- **二维容斥符号**：`S(x2,y2) - S(x1-1,y2) - S(x2,y1-1) + S(x1-1,y1-1)`，四个符号别记错。
- **加权前缀和**：要算 `Σ a[i][j]·i` 时，需先把 `a` 按行前缀和再乘 `i` 再按列前缀和，顺序错了结果就不对（见 `CF993H`）。
- **前缀和的"逆"是差分**：如果题目做的是"区间 +x"，那该去 `math/difference`。
