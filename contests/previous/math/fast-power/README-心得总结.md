# 快速幂与模运算

> 本目录共 **1** 个题解文件。

## 一、这一类题在考什么

快速幂是 O(log b) 求 a^b mod m 的标准工具，也是矩阵快速幂/逆元的基石。

## 二、关键思路与套路

- ABC448E 的难点不在快速幂本身，而在**取模会破坏整除信息**：在模 `m*10007` 的意义下计算，最后还原。
- 模板：`while (b) { if (b & 1) ans = ans * base % mod; base = base * base % mod; b >>= 1; }`。
- 延伸：模素数用费马小定理求逆元 `a^(p-2)`；模合数不能直接除。
- 指数与底数都要 `long long`；`mod == 1` 时结果恒 0，要特判。

## 三、最容易踩的坑

- 溢出与浮点是头号敌人：lcm 先除后乘，能整数开方就别用 sqrt。
