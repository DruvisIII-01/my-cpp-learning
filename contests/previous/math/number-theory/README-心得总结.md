# 数论

> 本目录共 **12** 个题解文件。

## 一、这一类题在考什么

gcd/lcm、素数筛、约数枚举、质因数分解是四大基础；**性质题比算法题多**。

## 二、关键思路与套路

- **筛法**：ABC475D 用 `2i+1` 压缩的埃氏筛处理 1e8 范围；CF1122E 用线性筛求最小质因子 spf。
- **O(√n) 约数枚举**：CF644D（取不超过 k 的最大约数）、CF667C（枚举公差）。
- **质因数分解定答案**：CF686D 取出现次数最多的质数构造最长整除链。
- **不变量/同余**：CF1109C（交换不改变下标模 gcd(x,y) 的余数）、CF1089C1（相邻 gcd 不变 ⇒ a[i] 最小是两侧 gcd 的 lcm）。
- **lcm 容斥**：ECF188C。
- **DP + 数论**：CF1086C（期望型决策 DP）、CF1122E（最小质因子 DP）。
- `lcm(a,b) = a / gcd(a,b) * b`，先除后乘防溢出。

## 三、最容易踩的坑

- 溢出与浮点是头号敌人：lcm 先除后乘，能整数开方就别用 sqrt。
