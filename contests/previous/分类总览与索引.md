# 分类总览与索引

> 由分类审计生成，记录每个 C++ 文件的最终归属与题目来源。
> 命名约定：`CF<轮次>` = Codeforces 比赛轮次号，`ABC<n>` = AtCoder Beginner Contest，`LG/B` = 洛谷题库，`ECF<n>` = Educational Codeforces Round，`CPL` = 来源不明的自命题。
> ⚠️ `CF<轮次>` **不是** contestId：例如 `CF640`→**1352**、`CF1107`→**2241**（Codeforces Round 1107, Div. 3）。
> 结构说明：2026-10 共三轮整理 —— ①全面分类审计与改名；②把六个基础算法目录合并为 `simple-algorithms/` 并新增 `sort`、`hash`；③新增 `graphs/tree-dp`、`graphs/shortest-path`、`graphs/mst`、`data-structures/dsu`。
