# 构造

> 本目录共 **16** 个题解文件。

## 一、这一类题在考什么

要求输出任意一组合法解。方法论：从特例/边界找规律 → 猜统一构造 → 打表验证。

## 二、关键思路与套路

- **分类讨论是常态**：CF640B（同奇偶拆分）、CF640G/CF686A（按 n mod 4 分块）、CF940D（按串首尾分类）。
- **对称/交替摆放**：CF644G 用 (i*a+t) mod m 错位填 1，天然保证行列计数；可行性条件是 n*a == m*b。
- **用数学结构造**：CF1090D 令 a[i] = p[i]*p[i+1]，相邻不互质、不相邻互质。
- **差分把"必须为 0"的位置求出来**：CF1119E 先差分求必 0 集合，再贪心放 1。
- 构造题"样例过了"≠正确，最好写 checker 或小规模对拍。

## 三、最容易踩的坑

- 卡在"想不出统一公式"时，先手玩 n = 1..6 的小数据。
